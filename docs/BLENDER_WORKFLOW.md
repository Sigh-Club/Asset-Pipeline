# Blender-to-Sprite Pipeline Workflow
## Imperium of Ash Asset Pipeline — 3D-to-2D Automation

## Why Blender?

User concern: Past Blender experience was frustrating.  
Solution: You never touch Blender's UI for repetitive tasks. The Python script (`render_8dir.py`) is the operator. Your job is ONLY:
1. Build the model
2. Set up materials using palette colors
3. Rig and animate (if character)
4. Run the script

Blender gives us these irreplacable wins:
- **Accurate isometric projection**: Camera math is exact, no eyeballing angles
- **8-direction automation**: Script rotates model/camera, renders all frames
- **LOD generation**: Same scene, three render resolutions in one pass
- **Normal & depth maps**: Generated from the same render for dynamic lighting
- **Reusability**: Change model → re-render ALL directions and animations automatically
- **Future-proof**: Models exist at full 3D fidelity. Need HD-2D later? Re-render at 4×. No redrawing.

## Prerequisites

- Blender 3.6 LTS or newer (free, download from blender.org)
- Python 3.10+ (bundled with Blender, but standalone knowledge helps)
- Your `.blend` files should be saved in `assets/characters/<unit_name>/model/`

## The Blender Scene Setup (Manual, One-Time Per Asset)

### Step 1: Unit Scale

Set scene unit scale to **pixel-native**:
- 1 Blender unit = 1 pixel in final render (at LOD0)
- A 96×128 character = 96 BU wide, 128 BU tall in Blender
- This makes math trivial: camera resolution = frame size directly

**How**: Scene Properties → Units → Unit Scale = 0.001 (if using metric) OR simply work in "None" units and treat 1 BU = 1px. The script sets render resolution to match.

### Step 2: Materials (Palette-Locked)

Use **Emission shaders** (not Principled BSDF). Why:
- No shading calculation = exact output colors match palette
- No light interaction artifacts
- Consistent across all renders
- Looks like "retro pre-rendered sprite" instantly

**Material setup per palette color**:
```
Shader: Emission
Color: HEX from grimdark_64 palette (e.g., Gunmetal Dark #1E1E1E)
Strength: 1.0
```

**Pro tip**: Create a material library in the `.blend` file named `PAL_GunmetalDark`, `PAL_ImperialGold`, etc. Reuse across all models.

### Step 3: Camera Rig (Script-Handled, but understand it)

The script creates an orthographic camera rig:
- Camera type: Orthographic
- Orthographic scale: Matches sprite height (e.g., 128 for 96×128 characters)
- Position: Isometric distance from origin
- Rotation: 30° elevation, 45° azimuth increments

You do NOT set this manually. The script creates an empty named `ISO_CAM_RIG`, parents the camera to it, and rotates the empty.

### Step 4: Lighting (Script-Handled)

Three-point grimdark lighting:
- **Key**: Warm rusty (#946848), upper-left, strength 2.0
- **Fill**: Cool blue (#345A78), lower-right, strength 0.5
- **Rim**: Gold (#D4A024), behind subject, strength 1.5

This is set automatically by the script. Only override if concept demands different mood.

## Running the Pipeline (The Easy Part)

### Single-Asset Render

```bash
cd /path/to/asset-pipeline
blender assets/characters/imperial_guardsman/model/imperial_guardsman.blend --background --python tools/blender/render_8dir.py
```

The script will:
1. Check scene for valid rig (create if missing)
2. For each animation (idle, walk, attack, hurt, die):
   a. Set animation range
   b. For each direction (N, NE, E, SE, S, SW, W, NW):
      i. Rotate rig to angle
      ii. For each frame in animation:
          - Render PNG with alpha
          - Save to `render/raw/<anim>/<dir>/frame_XX.png`
      iii. Also render LOD1 (50%) and LOD2 (25%) variants
3. Generate a manifest JSON: `render/manifest.json`

### Batch Render (All Characters)

```bash
python tools/blender/batch_render_all.py
```

Scans `assets/characters/*/model/*.blend` and runs render_8dir.py on each.

## Post-Render: The GIMP Step

Raw renders from Blender are smooth (anti-aliased, interpolated). For pixel-art authenticity, we run post-processing:

1. **Downscale to target** (if Blender rendered at 2× for supersampling)
2. **Quantize to palette** (nearest color in grimdark_64)
3. **Pixel cleanup** (remove stray single pixels, sharpen edges)
4. **Crop to tight bounds** (remove excess transparent space)
5. **Pad to uniform frame size** (all frames same dimensions for easy packing)

This is done by `tools/gimp/batch_pixelate.py`.

## From Renders to Sprite Sheet

After GIMP post-process:

```bash
python tools/packer/pack_sprites.py --source assets/characters/imperial_guardsman/render/processed/ --output assets/characters/imperial_guardsman/sheets/
```

Outputs:
- `imperial_guardsman_atlas.png` — packed sprite sheet
- `imperial_guardsman_atlas.json` — frame metadata (name, x, y, w, h, pivot)

## Troubleshooting Common Blender Issues

| Problem | Cause | Fix |
|---------|-------|-----|
| Render is blurry | Anti-aliasing on, no pixelation | Check compositor nodes, or post-process in GIMP |
| Colors don't match palette | Using Principled BSDF + complex lighting | Switch to Emission shader only |
| Black background in PNG | Alpha channel not enabled | Script sets `scene.render.film_transparent = True` |
| Feet slide between frames | Origin/pivot not at ground level | In armature, ensure root bone is at Z=0 |
| Directions look mirrored | Camera angle wrong (e.g., 60° instead of 45°) | Script uses exact angles; check rig rotation |
| Model too detailed for pixel size | High-poly model scaled down too far | Model at low-poly (~2000–5000 tris). Detail comes from texture, not geometry |
| File sizes huge | 4K renders with 100 frames | Script enforces LOD0 = 96×128 directly. Check render resolution settings |

## Best Practices

- **Keep models simple**: For a 96×128 sprite, a 5000-triangle model is MORE than enough. Most detail comes from color blocking (palette), not geometry.
- **Animate root bone, not camera**: The camera rig rotates around origin. Move the character by moving the armature root bone.
- **Use IK for feet**: Prevents foot sliding during walk cycles. Lock feet to ground plane.
- **Test one direction first**: Before running full 8-dir × 5 anim pipeline, render a single idle_N frame to verify colors, size, and clarity.
- **Save increments**: `imperial_guardsman_v01.blend`, `v02.blend`. Never overwrite the only source file.
